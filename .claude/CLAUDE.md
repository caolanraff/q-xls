# xls.q

A small kdb+/q library that wraps the built-in `.h` namespace (kdb+'s HTML/XML
helper functions) to write kdb+ tables to Excel's SpreadsheetML (`.xls`) XML
format, with support for per-cell styling — number formats, bold, and
conditional cell colouring — and appending additional tabs to an existing
workbook.

## Layout

- [xls.q](../xls.q) — the library: style definitions (`.xls.style.*`),
  encoding helpers, and the public API (`.xls.write`, `.xls.append`,
  `.xls.as`).
- [README.md](../README.md) — usage examples and available styles.
- [examples/](../examples/) — before/after screenshots referenced from the
  README.
- `file.xls` — sample output generated by the README example.
